# 10공방 스쿱 타워 (10makercream)

10공방 사이트에서 제작한 캐릭터 모델링 파일(.json, .glb, .zip)을 불러와, 와플 콘 위에 귀여운 스쿱 아이스크림 형태로 변형하여 높이 쌓아 올리는 캐주얼 3D 탑 쌓기 게임입니다.

---

## 1. 플레이 방법
- **스페이스바(`Space`)**, **엔터(`Enter`)**, **아래 방향키(`↓`)**, 또는 **화면 터치/클릭**으로 스쿱을 떨어뜨립니다.
- 중심에 맞춰 착지할수록 균형이 안정되고 콤보 보너스 점수를 획득합니다.
- 탑이 한쪽으로 치우치면 중심을 잃고 흔들리다 무너질 수 있으니 타이밍을 잘 맞춰보세요!

---

## 2. 주요 기능
1. **10공방 모델링 파일 연동 및 저장**:
   - `.json`, `.glb`, `.zip` 파일을 불러와 내 캐릭터 스쿱으로 플레이할 수 있습니다.
   - 불러온 캐릭터는 브라우저에 자동 저장되어 새로고침 후에도 유지됩니다.
2. **바닥 커스텀 색상**:
   - 하단 바닥 색상 피커로 원하는 2가지 타일 색상을 지정할 수 있습니다.
3. **서버 없는 정적 웹 앱 (GitHub Pages)**:
   - 별도의 백엔드 서버나 서버 비용 없이 브라우저 단독으로 실행됩니다.
